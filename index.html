The Research Background

A Friendly Duel in Client-Side Defense

KofiType is a cozy coffee-themed typing app with competitive WPM tracking and leveling. To keep the leaderboards honest, developer Amar created Guardian — a client-side anti-tamper system. He invited Javed to attempt to break it.

Amar's Defensive Objective

Ensure that players cannot open Notepad or Chrome DevTools to edit their saved WPM, level, or XP. Protect export files (.kofi) against tampering, inject cryptographic signatures, and introduce verification gates.

  • Hide variables via closure obfuscation
  • Use AES-256-GCM encryption with runtime keys
  • Encode encrypted data into invisible Unicode characters
  • Require a human Discord emoji reaction before stats import
  • Enforce SHA-256 bootloader self-integrity checks
Javed's Research Methodology

Demonstrate the fundamental cryptographic reality: Any secret or integrity check running purely inside an untrusted client (the user's browser) can be reverse-engineered, extracted, or bypassed.

  • Extract dynamic encryption keys from minified source
  • Reverse zero-width unicode into raw binary bitstreams
  • Build automated standalone payload generators (Forge)
  • Create Chrome MV3 Extension to hook window.fetch at document_start
  • Auto-respond to Discord approval checks with simulated reactions

Mathematical Security

The Token Derivation Algorithm

How KofiType calculates the SECURITY_TOKEN dynamically from its own minified JavaScript source code — and why browser architecture permits reverse engineering it.

KofiType Token Derivation Formula 
const rawSource = __KOFITYPE_CORE__.toString().replace(/\s+/g, '');

// 1. Compute SHA-256 hash of minified code
const msgBuffer = new TextEncoder().encode(rawSource);
const hashBuffer = await crypto.subtle.digest('SHA-256', msgBuffer);
const hashHex = Array.from(new Uint8Array(hashBuffer))
  .map(b => b.toString(16).padStart(2, '0'))
  .join('');

// 2. Take first 8 hex characters as 32-bit integer
const token = parseInt(hashHex.slice(0, 8), 16);
console.log("Live Token:", token);
